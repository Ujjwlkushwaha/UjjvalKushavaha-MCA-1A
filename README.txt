Full Stack Lab - Mini Projects
------------------------------
Open the index.html file inside each folder in a browser. No install needed.

01-concentric-circles  HTML + CSS
02-ten-cards           HTML + CSS            (needs internet for images)
03-todo-list           HTML + CSS + JS
04-chessboard          JS only (DOM + style) 
05-snake-ladder        HTML + CSS + JS
06-random-jokes        HTML + CSS + JS + API (needs internet)
07-university-search   HTML + CSS + JS + API (needs internet)

Tip for project 07: open it by double-clicking index.html (file://) or via
http://localhost. The API uses http, so it can be blocked if the page itself
is served over https.

08-express-routes      Express + EJS, 6 routes (GET and POST)
09-express-crud        Express + EJS, RESTful CRUD on products
10-product-api         Express JSON API + client-side rendered front end

For 08, 09 and 10 (Node.js must be installed):
  cd 08-express-routes     (or 09-..., 10-...)
  npm install
  npm start
Then open http://localhost:3000
Stop the server with Ctrl + C before starting another project (all use port 3000).
